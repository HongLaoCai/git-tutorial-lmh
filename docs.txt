4. Muốn bỏ các changes chưa commit. (VD đang làm tính năng mới, càng làm càng sai, chỉ muốn reset 1 vài file code để làm lại)

a.Chưa commit
chọn discard changes
hoặc dùng lệnh
git restore tenfile.abc

hoặc 
git checkout tenfile.abc

b.Đã commit
-Dùng git reset HEAD~1 đề lấy lại code, sau đó discard file đó đi
-Nếu có nhiều commit
Xem danh sách các commit

git log --oneline

sau đó chọn commit cần về ( ví dụ: 4b6bd5d)

Nếu về thẳng 1 branch nào đó (ví dụ: main)
1.Mở branch main ra, copy file đó, rồi paste ngược vào (trước kia hay làm cách này)
2.Dùng lệnh

5. Commit thiếu file. (VD commit xong chưa push lên thì nhớ ra chưa tăng version chẳng hạn, thì làm sao để include thêm cái change mới vào commit vừa tạo)

a.Dùng amend
Tiếp tục fix file, sau đó dùng lệnh
git commit --amend --no-edit

b.Dùng reset HEAD~1 về, fix file lại rồi commit lại
git reset HEAD~1   
fix file
git add .
git commit -m "commit"

Có thêm resbase nhưng ko dùng
6. Lỡ commit các file đáng ra nên nằm trong .gitignore (ví dụ, .env, file db dump nặng), làm sao để remove nó ra

a.Chưa push
Dùng reset HEAD~1 để khôi phục, discard file đó đi,  thêm file đó vào .gitignore, xong sau đó commit lại

b.Nếu lỡ push file qua nhiều commit (file nhạy cảm cần bỏ lịch sử trên git .env)
Quét và bóc sạch file .env ra khỏi TOÀN BỘ các commit cũ 
git filter-branch --force --index-filter \ "git rm --cached --ignore-unmatch .env" \ --prune-empty --tag-name-filter cat -- --all

Sau đó thêm .env vào .gitignore và commit lại

git add .
git commit -m "remove file .env from git"
git push origin main --force

7. Quay lại commit cũ. (VD ở commit A, làm sang commit B, đã push hết lên, nhưng lúc test thấy lỗi rất nhiều, muốn back về commit A làm lại)

a.Xem danh sách các commit (qua git graph, history, hoặc lệnh)
git log --oneline

sau đó dùng lệnh checkout về commit (ví dụ: 4b6bd5d)
git checkout 4b6bd5d

copy các file code đó, sau đó về lại branch cũ, paste vào rồi tiếp tục làm. Cách này thủ công và ko phù hợp với git
b.Có thể dùng HEAD nếu biết về commit bao nhiêu (ví dụ: 4b6bd5d là commit thứ 3)
git reset HEAD~3 
sau đó fix code và add . rồi commit lại. Cách này vẫn lưu lịch sử trên web


Cách chuẩn hơn 
- Reset cứng toàn bộ code và lịch sử ở Local về thẳng commit A (ví dụ: 4b6bd5d)
git reset --hard 4b6bd5d
- nếu commit B là commit vừa tạo) 
git reset --hard HEAD~1 
- Push đè (Force) lên Remote để xóa commit B trên server (ví dụ: main) (do xóa các commit cũ nên cần push luôn)
git push origin main --force

Sau đó mới tiêp tục làm

hoặc nếu 

git revert <ma_commit_B>

sau đó tiếp tục làm rồi push sau
